# `srcs/main.cpp` のドキュメント

このファイルはIRCサーバーアプリケーションのメインエントリーポイントです。

## 責務

- **コマンドライン引数の解析:** サーバー起動時に、正しい数の引数（`<port>`と`<password>`）があるかチェックします。
- **入力値の検証:** 提供されたポート番号が有効な範囲（1-65535）内であること、およびパスワードが空でないことを検証します。
- **シグナルハンドラの設定:** `SIGINT`、`SIGTERM`、`SIGQUIT`シグナルに対するハンドラを設定し、サーバーの正常なシャットダウンを保証します。`signalHandler`関数は`server.stop()`メソッドを呼び出します。
- **サーバーのインスタンス化と起動:** `Server`クラスのインスタンスを作成し、その`start()`メソッドを呼び出して接続の待受を開始します。
- **エラーハンドリング:** サーバーの作成と起動を`try-catch`ブロックで囲み、初期化中にスローされる可能性のある例外を処理します。

## グローバル変数

- `g_server`: `Server`インスタンスへのグローバルポインタ。これは`signalHandler`がサーバーオブジェクトにアクセスし、クリーンに停止させるために使用されます。

## 処理フロー

1.  `main`関数が呼び出されます。
2.  `argc`と`argv`を検証します。
3.  ポートとパスワードが解析・検証されます。
4.  `signal()`が呼び出され、終了シグナルに対する`signalHandler`が登録されます。
5.  `Server`オブジェクトがスタック上に作成されます。
6.  グローバルポインタ`g_server`が`server`オブジェクトのアドレスに設定されます。
7.  `server.start()`が呼び出され、メインのサーバーループが開始します。
8.  シグナルが補足されると`signalHandler`が実行され、`g_server->stop()`を呼び出した後、`exit()`で終了します。
9.  サーバーのセットアップ中に例外が発生した場合は、それが補足され、エラーメッセージが出力されます。
