# `srcs/Message.cpp` のドキュメント

このファイルは、生のIRCメッセージを解析し、そのコンポーネントに簡単にアクセスできるようにする`Message`クラスを実装しています。また、標準的な返信メッセージを作成するためのヘルパー関数も含まれています。

## IRCメッセージ形式

IRCメッセージは次の構造を持っています：
`[:<prefix>] <command> [<params>...] [:<trailing>]`

- **プレフィックス（オプション）:** メッセージの送信元に関する情報（例：ユーザーのニックネームとホスト）。
- **コマンド:** 特定のIRCコマンド（例：`PRIVMSG`、`JOIN`）。
- **パラメータ（オプション）:** コマンドのパラメータのリスト。
- **トレーリング（オプション）:** メッセージの最後の部分で、スペースを含むことができます。常にコロン（`:`）で始まります。

## `Message` クラス

### 責務

- **解析:**
    - `parse()`メソッドは、生の文字列メッセージ（末尾の`\r\n`なし）を受け取り、それを構成要素である`_prefix`、`_command`、`_params`、`_trailing`に分解します。
    - 中間パラメータと最後のトレーリングパラメータを区別するロジックを処理します。
- **データストレージ:**
    - `_prefix`: メッセージのプレフィックスを保存します。
    - `_command`: コマンドを保存します。
    - `_params`: トレーリング部分の前に現れるスペース区切りのパラメータを保存する`std::vector<std::string>`。
    - `_trailing`: メッセージのトレーリング部分を保存します。
- **ユーティリティ:**
    - `toString()`: 解析されたコンポーネントから生のメッセージ文字列を再構築します。これは主にデバッグやロギングに役立ちます。

### 解析ロジック (`parse()`)

1.  メッセージがコロン（`:`）で始まるかどうかをチェックして、`_prefix`を識別し抽出します。
2.  プレフィックス（もしあれば）の後の最初の単語である`_command`を抽出します。
3.  文字列の残りの部分を反復処理し、単語を`_params`ベクターに解析します。
4.  コロン（`:`）で始まるセグメントに遭遇した場合、行の残りの部分全体を`_trailing`パラメータとして扱い、解析を停止します。
5.  トレーリング部分のコロンが見つからない場合、最後の単語は単に`_params`に追加されます。

## 返信ヘルパー関数

このファイルには、`createReply`という名前の2つのグローバルヘルパー関数も含まれています。これらの関数は`CommandHandler`全体で使用され、クライアントに送り返すための標準的な数値応答を構築します。

- `createReply(int code, const std::string& client, const std::string& msg)`
- `createReply(int code, const std::string& client, const std::string& target, const std::string& msg)`

これらのヘルパーは、サーバー名をプレフィックス、数値応答コード、ターゲットクライアントのニックネーム、および返信メッセージを含む、IRCプロトコルに従って返信文字列をフォーマットします。これにより、返信生成が標準化され、コマンド処理コードがクリーンになります。
