# `srcs/Channel.cpp` のドキュメント

このファイルは、ユーザーが集まってコミュニケーションできるIRCチャンネルを表す`Channel`クラスを実装しています。

## 責務

- **状態管理:**
    - `_name`: チャンネル名（例：`#general`）。
    - `_topic`: チャンネルのトピック文字列。
    - `_key`: チャンネルのパスワード（`+k`モード用）。
- **モード管理:**
    - `_userLimit`: 許可される最大ユーザー数（`+l`モード）。`0`は制限なしを意味します。
    - `_inviteOnly`: チャンネルが招待制（`+i`モード）の場合は`true`。
    - `_topicRestricted`: チャンネルオペレータのみがトピックを変更できる（`+t`モード）場合は`true`。
- **メンバー管理:**
    - `_members`: 現在チャンネルにいるすべてのユーザーを指す`Client*`のベクター。
    - `_operators`: チャンネルオペレーターであるメンバーを指す`Client*`のセット。
    - `addMember()`、`removeMember()`、`isMember()`: メンバーリストを管理するメソッド。
    - `addOperator()`、`removeOperator()`、`isOperator()`: オペレーター権限を管理するメソッド。
- **招待管理:**
    - `_invitedUsers`: `+i`モードのときにチャンネルに招待されているニックネームのセット。
    - `addInvite()`、`removeInvite()`、`isInvited()`: 招待リストを管理するメソッド。
- **コミュニケーション:**
    - `broadcast()`: チャンネルのすべてのメンバーにメッセージを送信します。オプションで1人のクライアント（通常は送信者）を除外できます。このメソッドは、実際の送信を行うために`Server::sendToClient()`に依存しています。
- **ユーティリティ:**
    - `getMemberList()`: すべてのメンバーのニックネームをスペースで区切った文字列を生成し、オペレーターには`@`を前に付けます。これは`NAMES`コマンドの返信に使用されます。

## チャンネルのライフサイクル

1.  ユーザーが存在しないチャンネルに`JOIN`しようとすると、`Server::createChannel()`によって`Channel`オブジェクトが作成されます。
2.  ユーザーが正常に`JOIN`すると、`addMember()`を介して追加されます。新しいチャンネルに最初に参加したユーザーは自動的にオペレーターになります。
3.  チャンネルの状態（モード、トピック）は、`CommandHandler`で処理される`TOPIC`および`MODE`コマンドによって変更されます。
4.  ユーザーが`PART`または`QUIT`すると、`removeMember()`を介して削除されます。
5.  `removeMember()`の呼び出しによってチャンネルのメンバーがゼロになった場合、`Server`は`Channel`オブジェクトを削除し、アクティブなチャンネルのリストから削除します。
