# `srcs/Server.cpp` のドキュメント

このファイルは、IRCサーバー全体のライフサイクルと操作を管理するコアな`Server`クラスを実装しています。

## 責務

- **ソケット管理:**
    - `setupSocket()`: メインのリスニングソケットを作成し、ノンブロッキングに設定し、オプション（`SO_REUSEADDR`）を設定し、指定されたポートにバインドして、着信接続のリスニングを開始します。
- **接続ハンドリング:**
    - `start()`: メインのサーバーループ。`poll()`を使用して、すべてのアクティブなファイルディスクリプタ（サーバーソケットとすべてのクライアントソケット）のイベントを監視します。
    - `handleNewConnection()`: `accept()`を介して新しいクライアント接続を受け入れ、新しい`Client`オブジェクトを作成し、ポーリング対象のファイルディスクリプタのリストに追加します。
    - `closeConnection()`: クライアントの接続を閉じ、内部データ構造から削除し、リソースをクリーンアップします。
- **クライアント管理:**
    - ファイルディスクリプタをキーとするクライアントのマップ（`_clients`）を管理します。
    - `getClient()`: ファイルディスクリプタでクライアントを取得します。
    - `getClientByNickname()`: ニックネームでクライアントを取得します。
    - `removeClient()`: サーバーからクライアントを削除するロジックを処理します。これには、クライアントが参加していたチャンネルへの通知も含まれます。
    - `disconnectClient()`: クライアントの切断を開始するためのラッパーです。
- **データハンドリング:**
    - `handleClientData()`: クライアントソケットからデータを読み取れるようになったときに呼び出されます。`recv()`を使用してクライアントの受信バッファにデータを読み込みます。
    - `processClientMessage()`: クライアントのバッファに完全なメッセージが見つかると、この関数はそれを`Message`オブジェクトに解析し、`CommandHandler`に渡します。
    - `handleClientSend()`: クライアントソケットが書き込み可能になったときに呼び出されます。クライアントの送信バッファから`send()`を使用してデータを送信します。
    - `sendToClient()`: クライアントの送信バッファにメッセージを追加します。
- **チャンネル管理:**
    - チャンネル名をキーとするチャンネルのマップ（`_channels`）を管理します。
    - `getChannel()`: 名前でチャンネルを取得します。
    - `createChannel()`: 存在しない場合に新しいチャンネルを作成します。
    - `removeChannel()`: 空になったときにチャンネルを削除します。
- **状態管理:**
    - `_running`: `start()`のメインサーバーループを制御するブール値のフラグ。`stop()`はこれを`false`に設定します。
    - `stop()`: すべてのクライアントソケットを閉じ、すべてのクライアントとチャンネルを削除し、メインサーバーソケットを閉じることで、サーバーを正常にシャットダウンします。

## メインループ (`start()`)

サーバーの中心は`while (_running)`ループです。次のように動作します：

1.  `poll()`は、登録されているいずれかのファイルディスクリプタでイベントが発生するのを待ちます。
2.  ループは、イベントが発生したファイルディスクリプタを反復処理します。
3.  **イベントがサーバーソケット（`_serverFd`）で発生した場合**: 新しいクライアントが接続しようとしていることを意味します。`handleNewConnection()`が呼び出されます。
4.  **イベントがクライアントソケットで`POLLIN`の場合**: クライアントがデータを送信したことを意味します。`handleClientData()`が呼び出されます。
5.  **イベントがクライアントソケットで`POLLOUT`の場合**: ソケットが書き込み可能であることを意味します。`handleClientSend()`が呼び出され、キューに入れられたデータが送信されます。
6.  **エラーが発生した場合（`POLLERR`、`POLLHUP`）**: `closeConnection()`を介して接続が閉じられます。
